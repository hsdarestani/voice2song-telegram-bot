# Voice2Song Telegram Bot — ربات فارسی تبدیل وویس به آهنگ

این پروژه یک ربات تلگرام فارسی است که وویس/آواز/فایل صوتی کاربر را دریافت می‌کند، با **Spotify Basic Pitch** آن را به MIDI تبدیل می‌کند، سپس یک تنظیم ساده شامل ملودی، پد، بیس و درام می‌سازد و خروجی **MP3 + MIDI** ارسال می‌کند.

## امکانات اصلی

- منوی فارسی کامل داخل تلگرام
- تبدیل Voice / Audio / فایل صوتی به MIDI و MP3
- سهمیه روزانه و محدودیت طول فایل برای هر پلن
- مدل قیمت‌گذاری پیش‌فرض متناسب با بازار ایران
- پرداخت با لینک قابل ویرایش در پنل ادمین
- ثبت رسید پرداخت توسط کاربر و تایید/رد دستی در پنل
- پنل ادمین فارسی، RTL و ریسپانسیو
- آمار کاربران، تبدیل‌ها، درآمد تاییدشده، رسیدها
- مدیریت کاربر: تغییر پلن، انقضا، مسدودسازی، یادداشت
- مدیریت پلن‌ها: قیمت، سهمیه، حداکثر زمان فایل، لینک پرداخت
- پیام همگانی به همه کاربران یا کاربران پولی
- دیتابیس SQLite؛ مناسب شروع و MVP روی یک VPS

## مدل قیمت‌گذاری پیش‌فرض

| پلن | قیمت ماهانه | سهمیه روزانه | حداکثر طول فایل |
| --- | ---: | ---: | ---: |
| رایگان | ۰ تومان | ۳ تبدیل | ۳۰ ثانیه |
| مینی | ۲۹۰٬۰۰۰ تومان | ۲۰ تبدیل | ۶۰ ثانیه |
| پرو | ۶۹۰٬۰۰۰ تومان | ۸۰ تبدیل | ۱۲۰ ثانیه |
| استودیو | ۱٬۴۹۰٬۰۰۰ تومان | ۲۵۰ تبدیل | ۲۴۰ ثانیه |

همه قیمت‌ها، سهمیه‌ها و لینک‌های پرداخت از پنل ادمین قابل تغییر هستند.

## پیش‌نیازها

- Docker و Docker Compose؛ پیشنهاد اصلی
- یا Python 3.10/3.11، ffmpeg و libsndfile
- توکن ربات تلگرام از BotFather

## نصب سریع با Docker

```bash
unzip voice2song_telegram_bot.zip
cd voice2song_telegram_bot
cp .env.example .env
nano .env
```

در `.env` حتماً این‌ها را تنظیم کن:

```env
TELEGRAM_BOT_TOKEN=توکن_ربات
ADMIN_USERNAME=admin
ADMIN_PASSWORD=رمز_قوی
SECRET_KEY=یک_رشته_تصادفی_طولانی
PUBLIC_BASE_URL=https://your-domain.com
ADMIN_TELEGRAM_ID=آیدی_عددی_تلگرام_ادمین
```

سپس:

```bash
docker compose up -d --build
```

پنل ادمین:

```text
http://SERVER_IP:8080/admin
```

## نصب بدون Docker

```bash
sudo apt update
sudo apt install -y ffmpeg libsndfile1 python3.10 python3.10-venv
python3.10 -m venv venv
source venv/bin/activate
pip install --upgrade pip
pip install -r requirements.txt
cp .env.example .env
nano .env
python app.py
```

## تنظیم لینک پرداخت

1. وارد پنل ادمین شو.
2. برو به بخش «پلن‌ها و پرداخت».
3. برای هر پلن، لینک پرداخت زرین‌پال/آیدی‌پی/نکست‌پی/لینک کارت‌به‌کارت یا هر درگاهی که داری را وارد کن.
4. کاربر پس از انتخاب پلن، همان لینک را در ربات می‌بیند.
5. کاربر رسید را در ربات می‌فرستد و تو در بخش «رسیدها» تایید می‌کنی.

## نکات فنی مهم

- تبدیل صوت با Basic Pitch انجام می‌شود. اولین تبدیل ممکن است کندتر باشد چون مدل لود می‌شود.
- برای کیفیت بهتر، به کاربران بگو صدای تک‌ملودی و بدون نویز بفرستند.
- برای شروع MVP، SQLite کافی است. برای ترافیک بالا بهتر است پردازش را به Worker جدا و دیتابیس PostgreSQL منتقل کنی.
- `MAX_WORKERS=1` یعنی پردازش‌ها یکی‌یکی انجام شوند تا سرور ضعیف کرش نکند. روی سرور قوی می‌توانی ۲ یا بیشتر کنی.
- این پروژه پرداخت خودکار بانکی ندارد چون هر درگاه API متفاوت دارد؛ ولی لینک پرداخت و تایید دستی کامل پیاده‌سازی شده است. بعداً می‌توان Webhook درگاه پرداخت اضافه کرد.

## امنیت قبل از انتشار

- رمز ادمین را تغییر بده.
- `SECRET_KEY` طولانی و تصادفی بگذار.
- پنل را پشت HTTPS و ترجیحاً Nginx قرار بده.
- از پوشه `data/` بکاپ بگیر.
- توکن ربات را داخل گیت عمومی قرار نده.
